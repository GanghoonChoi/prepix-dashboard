# 대시보드 디자인 시스템 v2 (2026-10-12)

1단계 리디자인(`2026-10-07-dashboard-redesign.md`, 미니멀 모노)의 방향은 그대로 둔다.
이번에는 그 방향을 **컴포넌트와 규칙**으로 고정하고 전 페이지에 적용한다.

참고한 레퍼런스: shadcnblocks-admin. 219개 페이지를 전부 캡처하고 섹션별로 검토했다
(이커머스, 프로젝트 관리, 결제, AI 채팅 ×2, 설정·셸·인증).

## 왜 하는가

레퍼런스의 색 토큰은 stock shadcn neutral(#171717 / #737373 / #e5e5e5 / #f5f5f5)이고,
우리 토큰과 거의 같다. 차이는 색이 아니라 **컴포넌트와 규칙이 없다는 점**이다.
현재 화면 38장을 캡처해 보니 이렇다.

- **버튼:** 손으로 짠 `<button>` 234개, `primaryClass`·`secondaryClass` 259회.
  인증 화면과 404는 알약 모양이고 나머지는 각진 모양이다.
  비활성 버튼은 무거운 회색 블록이다.
- **검색창:** 3종. 회색 채움, 테두리 + 별도 버튼, 테두리 + 아이콘.
- **빈 상태:** 5종. 점선 박스, 테두리 박스, 잠금 화면, 아이콘 타일, 빨간 배너.
- **배지:** 4종. 테두리, 검정, 회색, 파란 점. 타임코드는 노란 칩이다.
- **카드:** 테두리 카드, 테두리 없는 포스터, 구분선 섹션, 그림자 카드(온보딩)가 섞여 있다.
- **폭:** 거의 모든 페이지가 944px 한 열이다. 표·그리드·설정이 모두 같은 폭을 쓴다.
- **헤더:** 프로젝트 탭마다 제목이 바뀐다(영상 제목 → "프로젝트 자료" → "프로젝트 멤버").
  팀 설정 제목은 "워크스페이스 설정"인데 내비는 "설정"이다.
- **표기:** 한국어 화면에 "38m / 1h 0m"이 나온다.
  날짜에 초까지 나온다("오전 12:00:26까지").
- **다크 모드:** 포스터 없는 프로젝트 타일이 배경에 묻힌다.
- **select:** 브라우저 기본 셰브론과 커스텀 세그먼트가 섞여 있다.

## 결정 사항 (2026-10-12, 사용자 승인)

- **방식 A:** 지금 스택(Tailwind v4 + HeroUI) 위에 자체 키트를 만든다.
  새 의존성은 없다. shadcn/Radix로 바꾸지 않는다.
- **범위:** 기반 + 전 페이지. 단계별 PR로 나눈다.
- **폭:** 두 가지(`wide` 1200 / `narrow` 768)에 리뷰 상세만 `full`.
- **색:** 기본은 모노. 상태(배지·안내·미터)에만 옅은 색을 쓴다.

## 하지 않는 것

- IA 변경. 내비 구성, 웹 프로젝트 생성 없음, 숨긴 화면은 그대로 둔다.
- 백엔드 변경, 새 기능, 문구 재작성. 표기 규칙(날짜·시간 단위) 수정은 예외로 한다.
- 차트 라이브러리, 칸반·간트, 페이지네이션, 컬럼 토글, 일괄 선택.
  우리 행 수는 수십 개 이하다.
- 대문자 eyebrow, 모노스페이스 스킨, 카드 안의 카드, 무지개 상태색, 파랑.

## 1. 기반: 토큰과 규칙

### 색

`app/globals.css`의 뉴트럴 토큰은 유지한다. 상태 톤만 추가한다.

| 톤 | 쓰는 곳 | 배경 / 글자 |
|---|---|---|
| `neutral` (기본) | 외부, 뷰어, 초안, 미리보기 준비됨, 버전 | `surface-secondary` / `foreground` 80% |
| `success` | 승인됨, 이용 중, 결제 완료 | `success` 10% / `--success-ink` |
| `warning` | 승인 대기, 좌석 대기, 결제 필요, 한도 임박 | `warning` 12% / `--warning-ink` |
| `danger` | 실패, 해지, 삭제, 오류 | `danger` 8% / `--danger-ink` |

- `--success/--warning/--danger`는 HeroUI 값을 그대로 쓴다.
- 글자는 AA 대비를 위해 `--*-ink`를 추가한다.
  - 라이트: 초록 #15803d, 앰버 #925f0a, 빨강 #b91c1c
  - 다크: #4ade80, #facc15, #f87171
- 버튼, 아이콘, 차트, 미터 채움은 모노로 둔다. 미터만 90% 이상일 때 warning을 쓴다.
- 파랑은 쓰지 않는다. 리뷰 상태의 파란 점은 톤 점으로 바꾼다.
  타임코드 칩은 neutral 모노 칩으로 바꾼다.

### 글자 (6단계)

| 역할 | 크기/굵기 | Tailwind |
|---|---|---|
| 페이지 제목 | 24/600, tracking-tight | `text-2xl font-semibold` |
| 카드·섹션 제목 | 16/600 | `text-base font-semibold` |
| 본문 | 14 | `text-sm` |
| 보조·컨트롤 | 13 | `text-[13px]` |
| 메타·라벨 | 12 | `text-xs` |
| 배지·단축키 전용 | 11 | `text-[11px]` |

### 간격·폭·모양

- **간격:** 4·8·12·16·24·32.
  - 페이지 좌우 24, 모바일 16.
  - 섹션 사이 32, 카드 안쪽 20, 카드 사이 16.
- **폭:** 페이지가 `Page width`로 고른다. 레이아웃 `main`은 패딩만 준다.
  - `wide` max 1200: 홈, 프로젝트, 프로젝트 상세, 멤버, 아카이브, 플랜 개요, 이용명세서, 스페이스 목록.
  - `narrow` max 768: 설정, 알림, 결제 정보, 초대 수락, 주문·명세서 상세.
  - `full`: 리뷰 상세.
- **모서리:** 컨트롤·배지 6, 카드·메뉴·포스터·다이얼로그 8, 아바타 원형.
- **컨트롤 높이:**
  - 기본 36. 640px 미만에서는 터치 대상 44.
  - 툴바·표 행 액션 32, 인라인 28.
- **버튼:** 전부 각진 모서리(6). 한 영역에 primary는 하나만 둔다.
  - 비활성 primary는 `opacity-40`만 준다. 회색 블록으로 칠하지 않는다.
  - 왜 비활성인지는 옆 문구로 보인다.
- **그림자:** 팝오버, 메뉴, 다이얼로그, Sheet, 코멘트 입력창에만 쓴다.
  나머지는 헤어라인으로 구분한다.

### 표기 (`lib/format.ts` 한 곳)

- **날짜:**
  - 표·목록은 `2026. 10. 12.`
  - 문장 안은 `10월 12일`
  - 기간은 `10월 12일 – 11월 11일`
  - 초 단위는 쓰지 않는다. 시각이 필요하면 `오전 9:30`.
- **상대 시간:** 기존 `ago()`를 옮겨 온다.
- **길이:**
  - 한국어 `38분`, `1시간 5분`
  - 영어 `38m`, `1h 5m`
  - 영상 길이 배지는 `0:06`
- **금액:**
  - 한국어 `129,000원`, 영어 `₩129,000`
  - 표에서는 오른쪽 정렬 + `tabular-nums`
  - 단위·분모는 작고 흐리게: `/ 석·월`, `/ 1시간`
- **개수:** 제목 뒤에 흐리게 붙인다(`프로젝트 4`).
- **메타:** ` · `로 잇는다.

## 2. 컴포넌트 키트 (`components/ui/`)

`components/ui.tsx`는 폴더가 되고 `components/ui/index.ts`가 전부 다시 내보낸다.
그래서 `@/components/ui` import 경로는 바뀌지 않는다.

`workspaces/shared.tsx`의 시각 요소도 여기로 옮긴다. 대상은 다음과 같다.

- 클래스 문자열, `Block`, `EmptyState`, `Notice`, `KeyValues`, `BackLink`, `ConfirmDialog`

도메인 요소(`TeamShell`, `SpaceBadge`, `SeatBreakdown` 등)는 제자리에 두되,

## 3. 셸

- **레이아웃:** `main`은 폭을 정하지 않고 패딩(좌우 24, 위 32)만 준다.
  폭은 `Page`가 정한다. 리뷰의 `wide` 분기는 `Page width="full"`로 옮긴다.
- **사이드바:** 240 폭, 13px 항목, 11px 섹션 라벨은 유지한다.
  - 스페이스 스위처를 32px 스페이스 타일 + 이름 13/600 + 보조 줄 11 흐림으로 바꾼다.
    보조 줄은 `개인 · Free`, `Business · 5석` 같은 형태다.
  - 헤더와 푸터는 고정하고 내비만 스크롤한다.
- **계정 메뉴:**
  - 맨 위에 이름·이메일 블록을 둔다.
  - 구분선으로 그룹을 나눈다: 계정 설정 | 언어·테마 | 약관 | 로그아웃.
  - 언어·테마는 `Segmented`로 바꾼다.
- **상단바:**
  - 위치 표시(스페이스 / 페이지)는 유지한다.
  - ⌘K는 `Kbd` 채움 칩으로 바꾼다.
  - 알림 배지는 최소 16px, 검정 채움, 10px/600.
  - 모바일 검색은 `IconButton` 하나로 둔다.

## 4. 페이지별 적용

### 개인

- **홈 `/dashboard` (wide)**
  - 환영 제목은 유지한다.
  - `StatStrip` 한 장: 남은 AI 시간(미터 포함) / 플랜 / 이번 달 영상.
  - 바로 하기는 카드 링크 3개로 둔다.
  - 최근 업로드는 `Poster` 그리드, 없으면 `EmptyState`.
- **플랜과 결제 `/dashboard/plan` (wide)**
  - 위쪽 요약 띠: 현재 플랜 · 다음 결제일 · 금액 · 결제수단 + 주 액션.
  - 플랜 카드는 선택형 카드로 바꾼다. 선택 시 2px 검정 테두리.
  - 쿠폰은 `SettingRow`, 환불은 `SettingsSection`.
  - **진행 중인 `feat/pricing-2026-10`이 머지된 뒤** 손댄다.
- **사용량 `/dashboard/usage`:** `MeterRow` 목록.
- **설정 `/dashboard/settings` (narrow):**
  - `SettingsSection`: 프로필 / 환경(언어·테마 `Segmented`) / 계정.
  - 계정 삭제는 `DangerZone`.
  - "미설정"이 이름 대신 나오는 표시 오류도 고친다.

### 스펙과 다르게 간 것

- **스위처 보조 줄:** 넣지 않았다. 지금 데이터로는 "개인 공간 / 내 공간"처럼 같은 말이 반복된다.
  플랜이나 좌석 수를 보여 주려면 데이터를 더 불러와야 해서, 필요해질 때 다시 본다.
- **StatStrip 모바일:** 2열이 아니라 1열로 쌓는다. 홀수 칸에서 빈 칸이 생기지 않게 하려는 것이다.
- **`SelectField` 대신 `Select`:** 네이티브 `<select>`를 그대로 바꿔 끼우는 형태로 만들었다.
- **e2e가 버튼 역할로 찾는 토글:** 알림 필터, 리뷰 회차·코멘트 필터가 해당한다.
  `Segmented`(radio)로 바꾸지 않고, 버튼 역할을 둔 채 `trackClass`/`segmentClass`로 모양만 맞췄다.
- **목록 데이터:** 프로젝트 목록에는 포스터, 영상 수, 안 읽음 열이 없고, 파일 목록에는 업로더가 없다.
  API가 내려주지 않는 값이라 자리만 두거나 열을 뺐다.
- **시각 표기:** 법정 기한과 결제 기한을 말하는 문장은 계속 KST 헬퍼로 표기한다(초 단위는 뺐다).
  표의 날짜 열만 `lib/format`을 쓴다.
- **에러 페이지:** 404만 큰 코드를 보여 준다. error 페이지에 보여 줄 실제 코드가 없어서다.
